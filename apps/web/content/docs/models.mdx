## Prices

Credits per 1M tokens. One credit is $1.

<PricingTable />

Prices are the provider's list prices plus {MARKUP_BPS / 100}%. There is no other fee.

- **Haiku 5.5** has two tiers. A request's prompt is its input, cache read and cache write tokens together. Above 100,000 the whole request is priced at the second tier.
- **Thinking** tokens are output tokens.
- **Minimum charge:** {ucrToCredits(MIN_CHARGE_UCR)} credit per request. It covers the two Solana transactions behind every request.
- Each request's cost is rounded up to the nearest 0.000001 credit.

## What a request holds

Before the model runs, a request holds its worst-case cost on your API balance:

- **Input:** text bytes divided by 3, at most the model's context window. It is priced at the 1-hour cache write rate if any `cache_control` has `ttl: "1h"`, at the 5-minute rate if there is any other `cache_control`, and at the input rate otherwise. Requests with images or documents are counted exactly with the provider's token counter.
- **Output:** `max_tokens` at the output rate. Thinking is part of `max_tokens`.
- **Web search:** `max_uses` searches, or {WEB_SEARCH_HOLD_USES} if it is not set, each with {WEB_SEARCH_RESULT_TOKENS.toLocaleString("en-US")} tokens of results.
- **Haiku 5.5** holds at the second tier once the input estimate passes {(100_000 * RESERVE_TIER_HEADROOM_BPS / 10_000).toLocaleString("en-US")} tokens.

Sonnet 5.5 with 6,000 bytes of text and `max_tokens: 1024`:

<HoldExample model="claude-sonnet-5-5" textBytes={6000} maxTokens={1024} />

When the request ends, the program burns its actual cost and releases the rest. You are never charged more than the hold: if the actual cost is higher, Unspent pays the difference.

One request can hold at most <Limit name="maxReservation" />. A request with a larger worst case gets `400 request_too_expensive`: lower its `max_tokens`.
